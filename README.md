# Coursework — Анализ рекламных интеграций и прогнозирование продаж

## Описание

Курсовая работа посвящена анализу данных о рекламных интеграциях и их влиянии на поведенческую воронку и продажи.  
В рамках проекта были выполнены подготовка и очистка данных, первичный анализ показателей, выявление факторов влияния на количество заказов, визуализация результатов и построение модели прогнозирования.

Исследование основано на таблице с метриками рекламных кампаний и пользовательского поведения: просмотры, добавления в корзину, заказы, охват, CPM, затраты, формат контента, месяц размещения и платформа.

Проект демонстрирует полный цикл аналитической работы — от предобработки данных до интерпретации результатов машинного обучения.

## Основные этапы проекта

**Подготовка и очистка данных:**  
приведение таблицы к удобному формату, обработка пропусков, преобразование типов данных, удаление дубликатов и подготовка признаков для моделирования.

**Разведочный анализ данных (EDA):**  
изучение распределений, проверка связей между показателями, анализ сезонности и выявление выбросов.

**Feature Impact Analysis:**  
определение наиболее значимых факторов, влияющих на количество заказов, с использованием корреляционного анализа и модели Random Forest.

**Визуализация результатов:**  
построение тепловой карты корреляций, графиков по месяцам и boxplot-диаграмм для интерпретации структуры данных.

**Модель прогнозирования:**  
построение и сравнение линейной регрессии и Random Forest для прогнозирования количества заказов.
